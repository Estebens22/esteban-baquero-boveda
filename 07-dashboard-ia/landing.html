01La idea

Un dashboard que solo pinta gráficas te deja el trabajo difícil a ti: decidir. Este lee la señal y propone qué hacer. La regla de oro: el código calcula (aritmética exacta, auditable) y el modelo interpreta — le pasas las cifras ya listas, no la tabla cruda, para que no alucine números.

datos → [calcular KPIs y señales] → [interpretar y decidir] → una acción concreta

02Corre el ejemplo en 10 segundos

El kit trae dashboard.py — solo librería estándar — y datos de muestra en data/:

cd kit
python3 dashboard.py --demo
python3 dashboard.py

Se genera un dashboard.html con las tarjetas de KPIs, las señales y la decisión. Sin API key decide por reglas; con OPENAI_API_KEY el modelo redacta la decisión.

03Las 3 piezas que importan

Carga que luego cambias sin tocar el resto

Hoy lee un CSV. Mañana cambias esa única pieza por una query a tu base de datos y los KPIs y la decisión quedan igual.

KPIs exactos y señales honestas

El código suma, divide y compara semana contra semana. Cada señal es una bandera clara: "ingresos ↓ 17%", "ROAS por debajo de 3x".

Una sola acción, medible

La decisión no te da diez tareas: te da una, accionable esta semana y medible. "Baja ads 15% y mide ROAS a 7 días", no "mejora el marketing".

04Llévatelo

Kit con dashboard.py, datos de muestra y el prompt de análisis. Reemplaza el CSV por tus datos y tienes un tablero que decide sobre tu negocio.
