01La idea

La voz no es magia: es un pipeline que puedes correr y medir pieza por pieza. El audio entra, se vuelve texto, tu lógica decide, y la respuesta sale hablada.

audio → [STT: habla→texto] → [tu lógica] → respuesta → [TTS: texto→habla] → audio

02Corre el ejemplo en 10 segundos

El kit trae voz.py — solo librería estándar:

cd kit
python3 voz.py --demo
python3 voz.py "hola, ¿qué puedes hacer?"

Sin API key corre en modo MOCK: el TTS escribe un .wav real (un tono por palabra) y el STT recupera el texto. Con OPENAI_API_KEY, Whisper transcribe y la API sintetiza de verdad — tras la misma interfaz.

03Las 3 piezas que importan

STT: habla → texto

Una sola interfaz, transcribir(wav). El mock es el andamio; el modo real es Whisper (API o local) sin tocar tu flujo.

TTS: texto → habla, con consentimiento

Usar una voz identificable exige consentimiento=True. Sin permiso, la síntesis se bloquea — a propósito.

El flujo de conversación

Un turno completo: STT → tu lógica (aquí enchufas tu LLM/agente) → TTS. El contrato no cambia cuando subes de mock a modelo real.

04Voz responsable

Consentimiento antes de clonar, etiquetar lo sintético, tratar el audio como dato personal y cero suplantación. La guía VOZ-RESPONSABLE.md lo resume en cuatro reglas — y la compuerta del kit aplica la primera por ti.

05Llévatelo

Kit con voz.py, la guía de voz responsable y la comparativa de opciones (local vs API). Enciende tu API key o conecta Whisper local y el mismo flujo habla de verdad.
